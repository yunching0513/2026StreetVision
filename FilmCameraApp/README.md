# Film Camera App

A full iOS application built with SwiftUI, AVFoundation, and CoreImage that allows users to take live photos or edit existing photos using 5 film simulation styles (Kodak Portra 400, Fuji Superia 400, Kodak Gold 200, Fuji Pro 400H, Ilford HP5).

## How to run

1. Open `FilmCameraApp.xcodeproj` in Xcode on your Mac.
2. Select your iPhone or a Simulator as the run destination.
3. If running on a physical iPhone, ensure you update the `Signing & Capabilities` to your Apple Developer account.
4. Click **Run** (Command + R).
