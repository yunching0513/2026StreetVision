# FilmCameraApp

A SwiftUI iOS Camera application that applies 5 unique 3D LUT filters based on countries: Japan, Netherlands, Taiwan, Germany, and France.

## Getting Started

Because this project was generated in an environment without Xcode, it is structured as a Swift Package that builds an iOS Application.

To open and run this project in Xcode on your Mac:
1. Open Xcode.
2. Choose **File > Open**.
3. Select the `FilmCameraApp` folder (the one containing `Package.swift`).
4. Xcode will automatically resolve the Swift Package and allow you to build and run the app on your iPhone or Simulator.
